# Vendored fonts

Self-hosted deliberately: the privacy policy promises no third-party requests,
"not even fonts loaded from somewhere else". These are fetched once at build
time and served from our own origin.

| Directory | Font | Licence |
| --- | --- | --- |
| `Noto Sans Regular/` | Noto Sans glyph ranges for the MapLibre basemap | SIL OFL 1.1 |

**The interface itself ships no webfont.** It uses the system stack, because a
thing you scan every day should be set in the face the reader's OS already
renders best — and because nothing to download is nothing to go wrong.

Noto Sans here is *not* used by the interface. MapLibre needs glyph PBFs to draw
map labels at all and cannot fall back to a system font for them, so these are
the map's only.

Refresh a font by re-fetching the `.woff2` from the upstream project. Nothing
here is generated by a build step.
