# Vendored fonts

Self-hosted deliberately: the privacy policy promises no third-party requests,
"not even fonts loaded from somewhere else". These are fetched once at build
time and served from our own origin.

| Directory | Font | Licence |
| --- | --- | --- |
| `ebgaramond/` | EB Garamond (variable roman + italic) | SIL OFL 1.1 — see `ebgaramond/OFL.txt` |
| `Noto Sans Regular/` | Noto Sans glyph ranges for the MapLibre basemap | SIL OFL 1.1 |

EB Garamond carries the whole interface; there is no separate sans or mono, so
the `--serif` stack's fallbacks (`Iowan Old Style`, `Palatino`) matter — with
`font-display: swap`, text renders in a real old-style serif before the files
land and if they never do.

Noto Sans is not used by the interface. MapLibre needs glyph PBFs to draw map
labels at all, and it cannot fall back to a system font for them.

Refresh a font by re-fetching the `.woff2` from the upstream project. Nothing
here is generated by a build step.
